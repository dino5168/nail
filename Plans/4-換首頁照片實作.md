# 4-換首頁照片實作

> 來源需求：[[4-換首頁照片]]　｜　進度：`Progress.md`

## 需求

把首頁第一張圖（Hero 區的 SVG 指甲插畫）換成 `Plans/Images/home01.png`（深藍色長方形美甲，搭配白色手繪花朵和水鑽）。

## 做法（2026-11-07）

- [x] 原圖是 417×396 的 PNG（259 KB）。用 sharp 轉成 WebP（品質 85），存成 `website/public/images/home-hero.webp`，檔案變成 **23 KB**。`Plans/Images/home01.png` 保留作為原始檔。
- [x] `website/src/app/[lang]/page.tsx`：Hero 改用 `<img>`
  - `src` 經過 `asset()` 加上 basePath（`/nail`）
  - 寫明 `width`／`height`，避免載入時版面跳動
  - 這張是首屏最大的元素（LCP），所以設 `fetchPriority="high"`
  - 最大寬度限制在原圖的 417px，大螢幕上不會放大糊掉
  - 圓角加柔和陰影：手機版滿版、只有下方圓角；桌機版四邊圓角
- [x] 替代文字放進兩語系字典 `home.hero.imageAlt`（`zh-tw.ts`、`vi.ts`）
- [x] 刪除不再使用的 `HeroNails` 插畫元件（`components/illustrations.tsx`）。作品集和服務卡片的佔位圖 `NailTile` 還在使用，保留。
- [x] 中文子集字型隨新的替代文字重新產生

## 驗證

- `npm run lint`、`npm run typecheck`、`npm run build`（`NEXT_PUBLIC_BASE_PATH=/nail`）都通過。
- 本機以 `/nail` basePath 提供靜態輸出，用無頭 Edge 截圖檢查：
  - 桌機 1366×900（zh-tw）：照片在右欄，標題在左欄，版面正常。
  - 手機 390×844（DevTools 協定模擬，zh-tw、vi）：照片寬 390px、高 370px、已載入，頁面寬度等於 390px，沒有水平捲動。
- 注意：Windows 上 Python `http.server` 不認得 `.webp`，會回傳 `application/octet-stream`，本機測試時要自己加上 MIME 類型。GitHub Pages 會正確回傳 `image/webp`。
