# 5-換首頁照片02實作

> 來源需求：[[5-換首頁照片02]]　｜　進度：`Progress.md`

## 需求

首頁「作品精選」的照片改用 Pexels（https://www.pexels.com/）的照片。

## 決議

- 「作品精選」顯示的是 `data/gallery.ts` 的前 4 筆（g01～g04），所以直接在這 4 筆填入照片。作品集頁的前 4 張也會一起換成照片，兩頁保持一致。
- 依原本的分類挑照片，色調配合網站的粉紫色系：

| 項目 | 分類 | Pexels 照片 | 攝影師 |
|---|---|---|---|
| g01 | 手繪造型 | [34871556](https://www.pexels.com/photo/34871556/) 紅色波浪彩繪 | Salim Da |
| g02 | 單色凝膠 | [20758448](https://www.pexels.com/photo/20758448/) 粉色凝膠＋花 | mehrab zahedbeigi |
| g03 | 法式 | [34997566](https://www.pexels.com/photo/34997566/) 法式白邊 | Salim Da |
| g04 | 延甲 | [10420563](https://www.pexels.com/photo/10420563/) 長杏仁形延甲 | PabloKlik |

- **仍標示「示意圖」**：這些是圖庫照片，不是本店作品。為了不讓客人誤會，照片右下角保留「示意圖」標示；滑鼠移到照片上會顯示攝影師名稱。
- 授權：Pexels License 可免費商用、不需要標示來源。來源仍記在 `gallery.ts` 的 `credit` 欄位，方便日後查詢或替換。

## 做法（2026-11-07）

- [x] Pexels 網站會擋命令列請求（403），API 需要金鑰；改用 Chrome 瀏覽 Pexels 搜尋（nail art、gel nails、french manicure、acrylic nails 等），把約 50 張候選照片排成一張總覽圖來挑選。
- [x] 照片從 Pexels 圖片 CDN 下載後，用 sharp 裁成 640×640（智慧裁切）並轉成 WebP（品質 80），存到 `website/public/images/gallery/g01～g04.webp`，每張 15～36 KB。
- [x] `website/src/data/gallery.ts`：新增 `credit`（攝影師、來源網址）欄位，g01～g04 填入 `image` 與 `credit`。
- [x] `website/src/components/GalleryGrid.tsx`：有 `credit` 的照片仍顯示「示意圖」；加上 `title`（攝影師名稱）與 `width`／`height`，避免載入時版面跳動。

## 驗證

- `npm run lint`、`npm run typecheck`、`npm run build`（`NEXT_PUBLIC_BASE_PATH=/nail`）都通過。
- 本機以 `/nail` basePath 測試：桌機 1366px 一排 4 張、手機 390px 兩欄 2×2，4 張照片都有載入（640×640），分類名稱和「示意圖」都看得到。

## 之後

拿到店內實際作品照片時，替換 `public/images/gallery/` 的檔案，並刪掉對應的 `credit`，「示意圖」標示就會消失。
