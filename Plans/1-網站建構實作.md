## 二、設計方向（依參考畫面）

- **色彩**：淡粉底 `#fdf0f4`、主粉 `#f4a7c3`（按鈕）、深莓紫 `#7a1f5c`（強調/插畫）、文字近黑 `#1c1418`。
- **字體**：標題用細字襯線大寫（Cormorant Garamond＋Noto Serif TC），內文用 Be Vietnam Pro＋Noto Sans TC（皆支援越南語變音符號）。
- **版面元素**：
  - 頂部白色導覽列：Logo／以粉色圓點分隔的選單／外框「預約」按鈕／語系切換／手機漢堡選單。
  - Hero：左側大標＋副標＋粉色「查看服務」按鈕，右側指甲插畫。
  - 「為什麼選擇我們」四欄卡片（粉色圖示＋細字標題＋說明），hover 浮起陰影。
  - 大段落品牌介紹，後半段文字漸淡（仿參考圖）。
  - 右下角浮動「LINE 聊天」按鈕（台灣常用；越南語系顯示 Zalo）。
- **RWD**：手機單欄、卡片直排；桌機最大寬度 1200px。

## 三、技術架構

- Next.js 16（App Router）＋ React 19 ＋ TypeScript ＋ Tailwind CSS v4。
- `output: 'export'` 純靜態輸出；`trailingSlash: true`；`basePath` 由環境變數 `NEXT_PUBLIC_BASE_PATH` 控制（CI 設為 `/nail`，本機為空）。
- 路由：
  ```
  src/app/
    (root)/layout.tsx + page.tsx   → "/"：依瀏覽器語言導向 /zh-tw/ 或 /vi/
    [lang]/layout.tsx              → 各語系的 root layout（html lang、Header、Footer）
    [lang]/page.tsx                → 首頁
    [lang]/about|services|gallery|contact|faq/page.tsx
    global-not-found.tsx           → 404
  ```
- 語系：`src/i18n/`，字典為 TypeScript 物件（`zh-tw.ts` 定義型別，`vi.ts` 必須符合同一型別，漏翻譯會編譯失敗）。
- 店家資料（電話、地址、營業時間、LINE/Zalo）集中在 `src/config/site.ts`。
