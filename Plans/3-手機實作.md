# 3-手機實作

> 來源需求：[[3-手機]]　｜　進度：`Progress.md`

## 問題

手機版點漢堡按鈕（☰）後，選單沒有出現。

## 原因

- 按鈕本身正常：點擊後狀態有切換（`aria-expanded="true"`），選單也從隱藏變成 `display: block`。
- 但選單的**高度是 0**。手機選單寫在 `<header>` 裡面，定位方式是 `position: fixed; top: 72px; bottom: 0`，而 `<header>` 套用了 `backdrop-blur`（CSS `backdrop-filter`）。
- 依 CSS 規範，設有 `backdrop-filter`（以及 `transform`、`filter` 等）的元素，會成為內部 `position: fixed` 子元素的定位基準。選單因此不是相對整個畫面定位，而是相對只有 72px 高的 header，`top: 72px` 到 `bottom: 0` 之間的高度就是 0。

## 修正（2026-11-07）

- [x] `website/src/components/Header.tsx`：把手機選單移到 `<header>` 外面（改成同層元素）
- [x] 選單 `z-index` 設為 35：低於 header（40），高於浮動聊天按鈕（30），開啟時會蓋住聊天按鈕
- [x] 加上按 Esc 關閉選單
- [x] `CLAUDE.md` 記下這個陷阱
